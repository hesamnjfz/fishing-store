# سیستم طراحی و ساختار کد

## هویت بصری (طبق نقشه راه: آبی / زرد تیره / مشکی / قرمز)
| نقش | توکن Tailwind | استفاده |
|---|---|---|
| آبی برند | `brand-*` (۵۰۰ = `#1F5FE0`) | لینک فعال، دکمه ثانویه، فیلتر انتخاب‌شده، هویت لوگو |
| زرد تیره | `gold-*` (۵۰۰ = `#D4A017`) | **فقط** CTA اصلی (افزودن به سبد، مشاهده محصولات) و تاکیدهای کوچک. متن روی آن همیشه `ink-900` |
| مشکی | `ink-*` (۹۰۰ = `#090B0E`) | هیرو، بخش تخفیف، فوتر، تایپوگرافی |
| قرمز | `alert-*` (`#D92D2D`) | **فقط** تخفیف، موجودی محدود، هشدار، حذف. هرگز برای تزئین |

قاعده: هیچ رنگی روی دیگری غالب نمی‌شود؛ زمینه‌ی صفحات روشن `ink-50` و کارت‌ها سفید است.

## تایپوگرافی
- فونت: **Vazirmatn** (Variable، وزن ۱۰۰ تا ۹۰۰)، تنها خانواده‌ی فونت پروژه
- عنوان‌ها `font-black`، متن `font-medium`. اعداد همیشه با `toFa()` / `fmt()` از `src/lib/format.ts` فارسی می‌شوند
- قیمت‌ها به تومان و با `tabular-nums`

## زبان بصری
- بافت اصلی برند: خطوط هم‌عمق (`Contours.tsx`) و مقیاس عمق سونار در هیرو
- گوشه‌ها: کارت `rounded-2xl`، دکمه‌ها `rounded-xl`، کاشی‌های بزرگ `rounded-3xl`
- انیمیشن فقط برای: فرود خط ماهیگیری در هیرو، کشوها، توست. `prefers-reduced-motion` رعایت می‌شود
- تمام استایل‌ها با ویژگی‌های منطقی (`ms-`, `pe-`, `start-`, `end-`, `border-s`) نوشته شده‌اند؛ پروژه RTL است

## ساختار
```
src/
  app/            layout.tsx (RTL + Provider) · page.tsx (ترکیب بخش‌ها) · globals.css
  lib/
    data.ts       دسته‌ها، محصولات، برندها، رنگ‌ها (Mock)
    filter.ts     applyFilters (فیلتر + مرتب‌سازی)
    store.tsx     StoreProvider: فیلترها، سبد، علاقه‌مندی، کشوها، توست، goShop()
    format.ts     toFa / fmt / discountPct
  components/
    Header.tsx    AnnouncementBar، Header، MegaMenu
    SearchBox.tsx جستجوی زنده
    Hero.tsx      هیرو سونار
    Sidebar.tsx   SidebarPanel (مشترک دسکتاپ/موبایل) + Sidebar (دسکتاپ)
    Shop.tsx      نوار ابزار، چیپ‌ها، شبکه محصولات، حالت خالی
    ProductCard.tsx · ProductArt.tsx (تصویرسازی موقت SVG)
    Sections.tsx  TrustStrip · Deals · Categories · Brands · Guides · Footer
    Overlays.tsx  MenuDrawer · FiltersDrawer · CartDrawer · Toast · BottomNav
    Drawer.tsx    کشوی عمومی (Esc، قفل اسکرول، aria)
```

## قراردادها
1. هر تغییر فیلتر از `useStore().setFilters` یا `goShop(patch)` انجام می‌شود؛ ساید‌بار، منو، هیرو و کاشی‌ها همه یک منبع حقیقت دارند.
2. کامپوننت جدید = یک فایل در `components/`؛ فقط از توکن‌های Tailwind بالا استفاده کنید (رنگ hex مستقیم ننویسید، به‌جز داخل `ProductArt`).
3. هزینه ارسال هرگز هاردکد نمی‌شود (نقشه راه، بخش ریسک‌ها): در سبد فعلاً فقط یادداشت توضیحی است و در فاز ۴ از تنظیمات ادمین/API خوانده می‌شود.
4. تصاویر واقعی محصول با `next/image` و S3 جایگزین `ProductArt` می‌شوند (فاز ۲).
5. صفحات قانونی (قوانین، حریم خصوصی، تماس با ما) برای اینماد از فاز ۰ باید مسیر داشته باشند؛ لینک‌های فوتر فعلاً `#` هستند.
