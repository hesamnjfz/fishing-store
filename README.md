# فروشگاه اینترنتی لوازم ماهیگیری رضایی — لندینگ / صفحه اصلی

نسخه‌ی اولیه‌ی فرانت‌اند بر اساس «نقشه راه توسعه پروژه» (Next.js 15 App Router + Tailwind CSS 3 + TypeScript).
داده‌ها فعلاً Mock هستند (`src/lib/data.ts`) و در فازهای بعد به API بک‌اند (Go/Gin) وصل می‌شوند.

## اجرا
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
Node 20 یا بالاتر لازم است. فونت وزیرمتن از بسته‌ی npm بارگذاری می‌شود (بدون نیاز به اینترنت در زمان اجرا).

## آنچه ساخته شده
- هدر چسبنده: جستجوی زنده با پیشنهاد آنی، منوی بزرگ دسته‌بندی، علاقه‌مندی، سبد خرید
- هیرو «سونار عمق»: انتخاب نوع ماهیگیری، عمق پیشنهادی و ست تجهیزات
- **ساید‌بار حرفه‌ای** (دسکتاپ چسبنده + کشوی موبایل): درخت دسته‌بندی چندسطحی، اسلایدر قیمت، برند، رنگ، موجودی و تخفیف، چیپ فیلترهای فعال
- شبکه محصولات با فیلتر و مرتب‌سازی زنده، کارت محصول، سبد خرید کشویی، علاقه‌مندی (ذخیره در localStorage)
- بخش تخفیف با شمارنده، کاشی دسته‌ها، برندها، راهنمای خرید، فوتر، نوار ناوبری موبایل

## مستندات برای ادامه کار
- `docs/DESIGN_SYSTEM.md` سیستم طراحی، ساختار کد و قراردادها
- `.cursor/rules/project.mdc` قوانین ثابت برای Cursor
